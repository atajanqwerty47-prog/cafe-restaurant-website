# Cafe Royal

Современный сайт для кафе/ресторана с меню, отзывами, контактами и блоком бронирования.

## Запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите приложение:
   ```bash
   python app.py
   ```
3. Откройте в браузере:
   ```text
   http://127.0.0.1:5000
   ```

## Структура

- `app.py` — Flask приложение
- `templates/index.html` — HTML страницы
- `static/style.css` — стили
- `static/script.js` — JavaScript
